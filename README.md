# Codex 订阅（精简版）

参考 [WSL043/dsh-codex-subscription](https://github.com/WSL043/dsh-codex-subscription)，实现多订阅管理、独立 provider，以及可选的精简生图工具。不是上游插件的配置补丁，也不依赖上游插件运行。

## 功能

- 设置 → **Codex 订阅**：简洁账号列表、浏览器 OAuth / 设备码登录、修改后缀、同账号重新登录、移除及退出全部账号。
- 每个订阅注册独立 `codex-sub-<随机固定 ID>` provider；单账号显示名为 `codex`，多账号显示为 `codex-后缀`。后缀默认分配随机字母，可用铅笔按钮修改；`codex-` 前缀固定。
- 后缀持久保存，回到单账号时只隐藏而不删除；支持 1–32 个字母、数字、下划线或连字符，首字符为字母/数字，不区分大小写查重。
- 账号名下方以小字显示认证状态和完整邮箱，状态在邮箱前；不显示或查询额度。状态依据本地令牌有效期：未过期为“认证有效”，过期为“待刷新”，不代表已做远程认证检查。
- 旧版自由名称安全迁移到后缀；内部 provider ID 和凭据不变。
- 在 DSH 原生模型选择器中直接选订阅及模型，不存在“当前活动订阅”。不同会话可以并行使用不同订阅。
- 每个 provider 使用独立 adapter、凭据记录和 OAuth 刷新锁。跨订阅不复用私有 replay/signature 数据。
- 重命名不变更 provider ID；重新登录只能更新原订阅账号，不能把已有会话悄悄改绑到另一个账号。
- 删除会撤销本地保存的凭据并注销 provider，不取消已发出的请求，也不修改历史会话。它不在 OpenAI 服务端撤销 OAuth 授权。

- 可选开启一个 `codex_image_generate` 工具：文生图、基于所选图片的图生图；不增加专门的图片查看器、画布、标注或编辑面板。

**不包含**：全局账号切换、对话请求的自动轮换/故障转移、语音、联网工具、远控、自定义模型选择器、配额预测、CLI 子代理或上游高级设置。生图工具的自动账号模式支持故障转移。

## 安装

当前目标版本：DSH **0.2.2-rc.1**、pi-ai **1.3.0**。其他版本尚未验证；版本不匹配时不要强行豁免安装。

```sh
git clone https://github.com/0xlic/dsh-codex-subscribe.git
cd dsh-codex-subscribe
npm install --ignore-scripts
npm test
```

在 DSH 中让助手使用 `plugin_manager` 安装此目录：

```json
{"action":"install_bundle","target":"/absolute/path/to/dsh-codex-subscribe"}
```

安装会修改当前 profile，影响该 profile 下的所有会话。无需启动额外服务器。若安装器提示重启，请重启 Harness；若首次安装即时应用，刷新现有 GUI 后打开设置即可。

可以和原插件共存：本插件不注册或占用原来的 `openai-codex` route，不读取、迁移或删除原插件凭据。确认本插件可用后，可自行在插件管理中停用原插件。

## 使用

1. 打开设置 → **Codex 订阅**，点击“添加账号”，选择“浏览器登录”或“设备代码登录”；无需预先输入名称。
2. 用户自行打开登录链接，选择对应 ChatGPT 账号并完成授权。浏览器已有登录态可能默认使用同一账号；添加另一个账号前，请在登录页面切换账号。设备码登录需要账号允许该方式。
3. 回到设置确认成功，在原生模型菜单中选择 `codex` 或 `codex-后缀` 下的模型。
4. 第二个订阅同样添加，无需退出或切换第一个订阅。

对话模型目录使用安装的 pi-ai 自带 Codex 目录，并非逐账号从远端动态同步。目录出现某模型不代表该订阅一定可调用；对话请求的上游权限/配额错误会原样进入 DSH 的错误处理，不会换账号重试。访问令牌过期时按需自动刷新；刷新令牌失效后使用同账号重新登录。

管理工具 `codex_subscriptions` 支持 `list`、`rename`（仅后缀）、`remove`、`remove-all`（仅本插件账号），与 UI 共用 Host 操作。登录/提交授权响应不暴露为代理工具。凭据通过 DSH credentials 的独立 grant 记录保存，不写入 bundle 配置、源码、会话消息或浏览器状态；请勿把授权码或 token 发到聊天中。

## 图像生成与修改

设置 → **Codex 订阅 → 图像生成**独立卡片，开关、模型、质量和账号修改后自动保存并生效，无需点击保存按钮。应用期间暂时禁用控件，防止并发旧设置覆盖；失败时显示错误并回退至上次生效的设置。默认关闭；关闭时不向模型暴露生图工具。设置通过 DSH Config editor 保存在当前 profile，Loader 负责重载本插件并注册/注销工具；不会修改其他插件配置。请先完成或取消正在进行的登录，再修改生图设置。已经发给服务端的请求不因关闭而撤销。

- 默认模型：`gpt-image-2`；质量：`auto`、`low`、`medium`、`high`。
- 实验模型：`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`，另支持 `xhigh`、`max`。这些是参考实现中的候选 ID，不保证当前订阅具有权限；不会自动切换生图模型。
- 生图工具的模型和账号选择独立于对话模型及其 provider。账号默认为“自动选择”：优先使用上次成功账号，该优先级通过 DSH 的独立 storage domain 保存，在重载、重启后保留（固定账号成功不改写自动模式偏好）；鉴权、HTTP、网络或无效图片响应失败时，依次尝试其余已登录账号，每个账号仅尝试一次，成功即停止，全部失败后才返回最终错误。固定选择账号时只使用该账号，失败不切换。
- 用户取消、全局超时、禁用、卸载或本地原始附件存储错误不触发账号切换。原图已保存后发生取消/禁用会保留原附件、停止后续可选写入并提示；预览存储或 Host 路径查询失败会降级为原附件交付，不把已生成结果变成需要重新生图的错误。
- 设置只在用户设置页修改；模型不能自行开启此能力、提升质量或切换账号。仅新增一个图像工具，原有订阅管理工具保持不变。

文生图调用：

```json
{"prompt":"一只坐在窗边的橘猫，水彩插画"}
```

图生图调用同一个 `codex_image_generate` 工具，添加 `referenceImages`（1–5 个当前会话中选定图片的附件 ID）：

```json
{"prompt":"保留原图主体与构图，将背景改为雪山","referenceImages":["sha256:<完整的64位十六进制摘要>"]}
```

本地图片先用 `read_image` 读取，再使用返回的图片附件 ID；已在对话中的图片直接使用其附件 ID。不能传路径、文件名或猜测其他会话的附件。空数组、无效引用会报错，不会悄悄退化成文生图。

0.3.4 的工具结果默认只展示状态、文件入口及尺寸；图片预览默认折叠，打开后才挂载 DSH 原生 gallery，技术文本与附件 JSON 合并到折叠详情。直接要图时在最终回复展示图片，避免工作步骤与最终回复重复大图。旧会话也可使用新 renderer，无需重新生成；历史最终回复不会被改写。

生成项目素材时，支持可选 `outputPath` 和 `delivery`：

```json
{"prompt":"草莓主题应用图标，透明背景","outputPath":"assets/strawberry-icon.png","delivery":"file"}
```

- 不指定 `outputPath` 时默认 `delivery: "image"`，最终回复展示图片；指定路径时默认 `delivery: "file"`，最终回复给出文件链接，不自动展示大图。两者可显式覆盖。
- 相对路径按会话**当前**工作目录解析，也可指定绝对路径；仅保存 PNG，不做伪 SVG/ICO 转换。精确尺寸、透明度校验和格式转换需另行后处理。
- 自动创建父目录，原样保存 PNG 字节；已有文件、目录或符号链接一律拒绝，提交时使用原子无覆盖发布，避免并发覆盖。已有目标会在远程生成前拒绝。
- 文件导出通过 DSH 挂载的 shell 与会话沙箱执行，不绕过限制、不自动提权。当前导出要求执行环境可访问 Host 运行时；不支持该映射的远程文件系统会在生成前明确拒绝。附件交付不依赖文件导出。
- 生成成功但指定路径保存失败时，结果保留原始附件与明确警告；只恢复保存已有 PNG，不重新生成/切换账号。若是沙箱拒绝，不换写入方式绕过。`delivery: "file"` 不指定路径时也可仅交付附件原图链接。
- 两种交付方式都保留图片和原始文件附件，后续仍可图生图编辑。

结果使用 DSH 原生图片预览，并附上**逐字节保存的原始 PNG 文件**及可用时的 Host 路径。不提供独立查看器或编辑 UI。再次修改本工具先前生成的图片时，通过当前会话日志定位原始 PNG，不使用可能缩小的预览；其他输入使用 DSH 保存的图片附件（上传或 `read_image` 时可能已按 DSH 限制规范化）。当前工具固定输出尺寸和背景为 `auto`。单账号尝试限时 5 分钟，自动模式下该账号超时可继续尝试其余账号；整次工具调用最多 30 分钟，用户取消、外层调用期限或整体超时会提前终止。

图片提示词及选择的输入图片会发送到 ChatGPT 订阅服务并可能消耗图片额度。鉴权沿用账号隔离的刷新锁；错误不返回原始 OAuth/服务端响应，401、403、429 提供简短提示。自动模式下，网络结果不确定仍会尝试后续账号：先前请求可能已在服务端完成，因此可能重复生成并消耗多个账号的额度；取消或停止也不能撤销已发送的请求。固定账号模式不会切换账号重试。

## 开发与测试

```sh
pnpm install --ignore-scripts
pnpm test
pnpm run check
pnpm pack
```

运行文件为普通 ESM + 原生 Client loader factory，无需构建步骤。测试使用合成凭据和离线 provider，不发送真实模型请求或消耗订阅额度。

- [accounts.js](<src/accounts.js>)：独立凭据记录及锁内刷新桥。
- [adapter.js](<src/adapter.js>)：每订阅单独 adapter 与原生 Codex transport 映射。
- [login.js](<src/login.js>)：用户登录状态机，临时授权结果先隔离后提交。
- [subscriptions.js](<src/subscriptions.js>)：生命周期和 UI/工具共用操作。
- [index.js](<src/index.js>)：DSH 服务接线和受认证 RPC。
- [images.js](<src/images.js>)：单一生图工具、交付模式、会话附件校验、原图输出与图生图请求。
- [image-export.js](<src/image-export.js>)：会话路径解析、沙箱内 PNG 导出和原子无覆盖发布。
- [image-settings.js](<src/image-settings.js>)：模型/质量配置、账号候选排序及 Config editor 持久化。
- [image-accounts.js](<src/image-accounts.js>)：自动模式最近成功账号的独立存储与卸载清理。
- [client.js](<client.js>)：原生设置页，支持中英文及主题 token。
